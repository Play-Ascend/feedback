# Play Ascend feedback

Bug reports and feature requests for [Play Ascend](https://www.play-ascend.com): the Tracker, Ascend Companion, Ascend AI, Esports and the website.

## Report a bug

- **On Discord (easiest):** post in **#bug-reports** in the [Ascend community](https://community.play-ascend.com). Pick a tag for the product. Every post is copied here as an issue, and the bot replies in your post with the link.
- **On GitHub:** [open an issue](https://github.com/Play-Ascend/feedback/issues/new/choose) with the bug report form.

Search the [open issues](https://github.com/Play-Ascend/feedback/issues) first. If someone already reported it, add a 👍 or a comment with anything new instead of opening a duplicate.

## What happens next

We triage every new issue. When something is fixed or closed, the issue closes here and, for Discord posts, the bot says so in your post.

## Please don't post

- Account, payment or order problems: open a ticket in **#create-ticket** on Discord, or email info@play-ascend.com.
- Personal details. Issues here are public.
- Security vulnerabilities. Email info@play-ascend.com instead.
